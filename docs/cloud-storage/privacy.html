Privacy policy

GreenFuze Cloud Storage is a local cloud connector used by GreenFuze game-library applications. GreenFuze operates no backend for the connector and does not collect, receive, sell, or share Google user data through it.

Released clients

The first released client is the open-source Cloud Storage extension. Future GreenFuze clients using this OAuth application must follow the same data-use limits described in this policy. Their source or product information will be linked from this page when released.

Google data accessed

After you authorize Google Drive, the connector requests the restricted read-only https://www.googleapis.com/auth/drive.readonly scope. It uses this permission to:

  • show folders while you choose a game-library source;
  • read folder and file metadata below the folder you selected;
  • recursively discover supported game packages in that folder; and
  • download a selected package to your computer when you request installation.

The scope technically permits reading the connected Drive because Google's narrower per-file scope cannot enumerate existing descendants of a folder selected inside a local desktop client. The released connector limits its discovery and download operations to your selected folder. It does not request permission to write, modify, or delete Google Drive files.

Local storage

The client stores the provider account identifier, selected-folder identifier, OAuth authorization, installation records, and downloaded game files locally on your computer. The released Windows client protects OAuth tokens with Windows Data Protection API for the current Windows account and never stores your Google password.

Data transfer, sharing, and limited use

Authorization and file requests are sent directly between your computer and Google over HTTPS. The connector does not transmit Google user data or OAuth tokens to GreenFuze or another third party.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is not sold; used for advertising, credit decisions, or surveillance; or used to train generalized artificial-intelligence or machine-learning models.

Retention and deletion

Disconnecting Google Drive in a client removes its locally stored authorization, account identity, and selected-folder configuration, and the released client also attempts to revoke the authorization with Google. You can independently revoke access at any time through Google Account connections.

Downloaded files remain on your computer until you uninstall or delete them. Disconnecting the connector never deletes files from Google Drive.

Contact

Privacy questions and deletion concerns can be submitted through the public support tracker or sent to the developer contact address published on the Google OAuth consent screen.
