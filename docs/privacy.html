Privacy policy

Cloud Storage is a local Playnite extension developed and published by GreenFuze. It has no developer-operated server, telemetry, analytics, advertising, or user-tracking system. GreenFuze does not collect, receive, sell, or share personal data through the extension.

Data accessed

When a player connects a provider, Cloud Storage requests read-only access:

  • Google Drive: restricted drive.readonly, which technically permits reading all files in the connected Drive. This is required because Google’s per-file scope cannot enumerate existing descendants of a selected folder.
  • Microsoft OneDrive: delegated Files.Read and User.Read.

The extension reads account identity, folder and file metadata, and file contents needed for visible library-discovery and installation features. Cloud Storage’s code limits Google discovery and downloads to the concrete folder selected in its Playnite-native browser, even though the OAuth scope is broader. It does not request provider write or delete permissions and does not modify cloud files.

Local storage

Cloud Storage keeps provider account identifiers, selected-folder identifiers, encrypted OAuth tokens, installation manifests, installed game files, and ordinary Playnite diagnostic logs on the player’s computer.

OAuth tokens are encrypted with Windows Data Protection API for the current Windows account. The extension never stores account passwords.

Data transfer and sharing

Authentication and file requests are sent directly from the player’s computer to Google or Microsoft over HTTPS. Those providers process data under their own privacy policies. Cloud Storage does not send provider data or OAuth tokens to the plugin author or another third party.

Cloud Storage’s use of information received from Google Workspace APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is not sold, used for advertising or credit decisions, or used to train generalized AI or machine-learning models.

Retention and deletion

Disconnecting a provider and saving settings removes its locally stored authorization, account identity, and selected-folder configuration. Cloud Storage also attempts to revoke Google authorization remotely.

Players can revoke access in Google Account connections or Microsoft account consent management. Work or school Microsoft accounts can use My Apps.

Playnite may retain extension settings according to its backup behavior. Installed games remain below the player’s configured managed storage root until the player uninstalls or deletes them. None of these actions deletes files from Google Drive or OneDrive.

Contact

Privacy questions and deletion concerns can be submitted to GreenFuze through the public GitHub issue tracker.
