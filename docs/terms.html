Terms of service

Cloud Storage for Playnite is open-source software developed and published by GreenFuze. It connects a user-selected cloud folder to the user’s local Playnite library.

Permitted use

You may use the extension only with accounts, files, and software you are authorized to access. You are responsible for complying with applicable laws, software licenses, and the terms of Google Drive, Microsoft OneDrive, and Playnite.

Account access

The extension acts only after you authorize a provider and select a folder. You can disconnect the provider through the extension or revoke authorization through the provider’s account controls.

Local changes

Installation and uninstall operations modify files below the managed local storage directory you configure. Review prompts carefully and maintain backups of important game saves. The extension does not modify or delete cloud files.
