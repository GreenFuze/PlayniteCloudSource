A local cloud connector for GreenFuze game-library applications

Your cloud folder, available in your game library.

GreenFuze Cloud Storage lets you authorize Google Drive, choose a folder, discover its game packages recursively, and download a selected package to your own computer.

Application identity

One connector, multiple GreenFuze clients

GreenFuze Cloud Storage is the shared Google Drive integration for game-library software developed by GreenFuze. Its first publicly released client is the open-source Cloud Storage extension.

The same GreenFuze name and cloud-and-library mark are shown on the Google OAuth consent screen. A client using this connector must perform the same user-visible authorization, folder selection, discovery, and download flow described here.

How it works

Explicit authorization and local use

1

Authorize Google Drive

The client opens Google's OAuth consent flow. GreenFuze never receives your Google password.

2

Choose a folder

You browse your Drive and explicitly choose the concrete folder that the client will use as its game source.

3

Discover and download

The local client reads that folder recursively, displays supported game packages, and downloads a package only when you request installation.

Google data use

Read-only and user-directed

GreenFuze Cloud Storage requests Google's restricted, read-only drive.readonly permission. The narrower per-file scope cannot enumerate the existing descendants of a folder selected inside a local desktop client, which prevents the connector from maintaining a recursively discovered library.

Although the OAuth scope technically permits reading the connected Drive, the released connector limits discovery and downloads to the folder you select. It never modifies or deletes Google Drive files.

Google Drive requests travel directly between your computer and Google. GreenFuze operates no storage backend for this connector and does not receive your files, OAuth tokens, or library data.
