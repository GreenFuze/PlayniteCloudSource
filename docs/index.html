How it works

Explicit access, local installation

1

Connect a provider

Sign in through the provider’s system browser flow. Cloud Storage never receives your password.

2

Choose one folder

Google Picker chooses the concrete folder Cloud Storage will scan. Drive roots are intentionally not accepted.

3

Install through Playnite

Archives, installer bundles, and ROMs are discovered below that folder and downloaded directly to your managed local game directory.

Google data use

Only what the feature needs

Cloud Storage requests Google’s restricted, read-only drive.readonly permission. Google’s per-file scope cannot enumerate the existing descendants of a selected folder, so it cannot provide an automatically updated recursive game library.

The OAuth scope technically permits reading the connected Drive, but Cloud Storage’s code limits discovery and downloads to the concrete folder you select through Google Picker. It never modifies or deletes Drive files.

Provider requests travel directly between your Windows PC and Google. There is no developer-operated backend, telemetry, advertising, or sale of user data.
