A Playnite library extension

Your cloud folder, ready to play.

Cloud Storage turns one folder you choose in Google Drive or Microsoft OneDrive into an installable Playnite game library.

Download the latest release View the source

How it works

Explicit access, local installation

1

Connect a provider

Sign in through the provider’s system browser flow. Cloud Storage never receives your password.

2

Choose one folder

For Google Drive, Google Picker grants the extension access only to the concrete folder you select. Drive-wide access is not requested.

3

Install through Playnite

Archives, installer bundles, and ROMs are discovered below that folder and downloaded directly to your managed local game directory.

Google data use

Only what the feature needs

Cloud Storage uses Google’s drive.file permission to read metadata and download game-package files from the folder you deliberately share through Google Picker.

Provider requests travel directly between your Windows PC and Google. There is no developer-operated backend, telemetry, advertising, or sale of user data.

Read the complete privacy policy.

Open source and inspectable

The extension is licensed under Apache-2.0. Its authentication, storage, installation, and uninstall behavior can be reviewed publicly.
